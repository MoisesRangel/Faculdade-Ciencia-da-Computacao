2. Border (ocupa espaço) vs. Outline (flutua por fora)

Sem borda Com border (empurra os vizinhos) Com outline (não empurra ninguém)

3. Alinhamento (text-align)

Padrão (left): O texto fica alinhado à esquerda.

Center: O texto fica centralizado na caixa.

Right: O texto encosta na direita.

Justify: O texto estica as palavras para encostar tanto na margem esquerda quanto na direita, igual a uma coluna de jornal impresso.

4. Espaçamentos de Texto

Padrão do navegador:
Observe como as linhas, as letras e as palavras ficam próximas umas das outras no comportamento padrão sem ajustes.

Com line-height (1.8), letter-spacing (2px) e word-spacing (8px):
Observe como o texto ganha respiro vertical entre as linhas e afastamento horizontal entre letras e palavras.

5. Tipografia (Fontes)

Texto padrão: Fonte com serifa padrão do navegador, tamanho normal (16px), peso normal.

Texto estilizado: font-family sem serifa (Arial), font-size maior (20px), font-weight negrito (700) e font-style itálico.
